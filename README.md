# Guia de Estudo PMP — WBS / EAP

Material principal: `index.html` + `style.css` + `app.js`.

## Como usar

1. Extraia o ZIP (quando distribuído) ou abra `index.html` diretamente no navegador.
2. Use a navegação lateral para estudar por seção.
3. Faça o checklist e o simulado no final.
4. O botão “Imprimir / salvar PDF” usa a impressão do navegador e aplica um layout de estudo.
